# Bidou AI Bundled OFL Fonts

All fonts in this directory are licensed under the SIL Open Font License (OFL 1.1) and are permitted for commercial use, bundling, and distribution.

## Bundled Font Files
1. `BebasNeue-Regular.ttf` — Bebas Neue by Ryoichi Tsunekawa (Bold display sans)
2. `Anton-Regular.ttf` — Anton by Vernon Adams (Heavy condensed sans)
3. `Oswald.ttf` — Oswald by Vernon Adams, Kalapi Gajjar, Cyreal (Variable sans)
4. `Montserrat.ttf` — Montserrat by Julieta Ulanovsky, Sol Matas, Juan Pablo del Peral, Jacques Le Bailly (Variable sans)
5. `PlayfairDisplay.ttf` — Playfair Display by Claus Eggers Sørensen (Editorial serif)
6. `AlexBrush-Regular.ttf` — Alex Brush by TypeSETit (Signature script)

## International Character Support
Every font in this directory is tested and verified to support full Latin-1 supplement and French accented characters:
`É, è, ê, ë, à, â, ç, î, ï, ô, û, ù, œ, æ`
