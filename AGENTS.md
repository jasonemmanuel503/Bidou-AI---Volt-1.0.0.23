# Project Guidelines

## GitHub Commit & Push Policy

- **No Automatic Commits or Pushes**: Do not automatically commit or push code changes to the remote GitHub repository.
- **Explicit Authorization Required**: At the end of every task where files are edited, created, or modified:
  1. Explicitly list and describe the changes made.
  2. Ask the user for authorization to commit and push the changes to GitHub before taking any git action.
  3. Only commit and push when the user gives direct, explicit permission.
