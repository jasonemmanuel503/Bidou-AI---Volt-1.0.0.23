# Migration `20261002000000_multi_supplier_and_promo_credits.sql`

## What This Migration Does (Plain Words)
1. **Fixes a critical security vulnerability** by revoking `EXECUTE` permission from `public`, `anon`, and `authenticated` on all money-moving `SECURITY DEFINER` database functions (`refund_credits`, `debit_credits`, `grant_purchase`, `ensure_wallet`, `reserve_credits`, `reserve_credits_for`, `settle_reservation`, `sweep_expired_reservations`, `supplier_spend_today_usd`), granting execution exclusively to `service_role`.
2. **Splits user wallets into two buckets**:
   - `balance`: Paid credits (works on every model).
   - `promo_balance`: Free signup welcome credits (`500` credits for new signups), spendable **only** on models with `promo_eligible = true` (Cloudflare FLUX.1 Schnell, FLUX.2 Klein 4B, and Google Nano Banana 2 Lite).
   - `reserve_credits_for` draws from `promo_balance` first when `p_promo_eligible = true`.
   - `settle_reservation` consumes promo credits first and refunds any unused promo/paid credits back to the exact bucket they came from.
3. **Adds Multi-Supplier Routing & Cost Tracking Tables**:
   - `model_suppliers`: Priority-ordered suppliers per model (`kie` -> `google` for Veo, `cloudflare`, `alibaba`, `musicapi`).
   - `supplier_status`: Per-supplier kill switch, circuit breaker (`tripped_until`), and daily USD spend cap.
   - `plan_limits`: Max video seconds and monthly premium generation caps per plan tier.
   - `provider_cost_ledger` & `v_profit_daily`: Real-time per-variant supplier cost, revenue floor, and margin analytics.
4. **Updates Prices & Thresholds**:
   - Credit packages: Starter `2,000 FCFA` (1,500 cr), Creator `5,400 FCFA` (5,500 cr), Pro `16,000 FCFA` (18,000 cr), Studio `42,000 FCFA` (53,000 cr).
   - `award_tier_badge()` lifetime spend thresholds updated to match (promote-only; never demotes existing users).
   - Updates `ai_models.credit_cost` to match `npm run pricing:audit` and seeds the 4 new models (`img_cf_flux1_schnell`, `img_cf_flux2_klein_4b`, `vid_wan_3_0_standard`, `vid_wan_3_0_prime`) with `active = false` and `licensing_verified = false`.
5. **Enables Realtime**: Adds `credit_wallets`, `generation_jobs`, and `generation_job_variants` to `supabase_realtime`.

## Verification Queries (Run After Migration)

### 1. Verify Security Definer Lockdown
```sql
select
  p.oid::regprocedure as function_signature,
  has_function_privilege('anon', p.oid, 'EXECUTE')          as anon_can_exec,
  has_function_privilege('authenticated', p.oid, 'EXECUTE') as auth_can_exec,
  has_function_privilege('service_role', p.oid, 'EXECUTE')  as service_role_can_exec
from pg_proc p
join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and p.prosecdef = true
order by p.proname;
```
**Expected**: `refund_credits`, `debit_credits`, `grant_purchase`, `ensure_wallet`, `reserve_credits`, `reserve_credits_for`, `settle_reservation`, `sweep_expired_reservations`, and `supplier_spend_today_usd` all show `anon_can_exec = false`, `auth_can_exec = false`, `service_role_can_exec = true`. `verify_admin_pin` and `admin_set_platform_stat` remain `true`.
